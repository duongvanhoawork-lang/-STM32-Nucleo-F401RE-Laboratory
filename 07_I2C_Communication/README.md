# 🔗 I2C Communication

## 📝 Overview
This section covers the Inter-Integrated Circuit (I2C) communication protocol on the STM32 Nucleo-F401RE. I2C is a synchronous, multi-master, multi-slave, packet switched, single-ended, serial communication bus widely used for attaching lower-speed peripheral ICs to processors and microcontrollers in short-distance, intra-board communication.

## 📂 Directory Structure
- `I2C_Communication.docx`: Detailed lab report and documentation for the I2C communication exercises.

## 🎯 Learning Objectives
- Configure I2C as a Master to communicate with slave devices.
- Understand device addressing and read/write operations.
- Transmit and receive data using polling, interrupts, and DMA.
- Interface with common I2C sensors (e.g., IMUs, temperature sensors, EEPROMs).
