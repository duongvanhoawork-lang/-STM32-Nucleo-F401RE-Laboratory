# 🔌 SPI Communication

## 📝 Overview
This section covers the Serial Peripheral Interface (SPI) communication protocol on the STM32 Nucleo-F401RE. SPI is a synchronous serial communication interface used for short-distance communication, primarily in embedded systems.

## 📂 Directory Structure
- `SPI_Communication.docx`: Detailed lab report and documentation for the SPI communication exercises.

## 🎯 Learning Objectives
- Configure SPI in Master and Slave modes.
- Understand CPOL (Clock Polarity) and CPHA (Clock Phase) settings.
- Transmit and receive data using polling, interrupts, and DMA.
- Interface with SPI peripherals (e.g., sensors, displays, memory).
